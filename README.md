# Health Insurance Fraud Detection System

This project is an AI-powered Health Insurance Fraud Detection System developed as a Capstone Project at IIT Patna. The system uses a trained XGBoost machine learning model to analyze health insurance claims and predict the probability of fraudulent activity.

The application takes patient information, provider details, financial data, and claim-related features as input, performs preprocessing using a trained transformer pipeline, and generates fraud risk predictions in real time through an interactive Streamlit interface.

## Features
- Real-time fraud prediction
- XGBoost-based machine learning model
- Automated feature transformation pipeline
- User-friendly Streamlit dashboard
- Probability-based fraud risk analysis
- Displays model performance metrics

## Technologies Used
- Python
- Streamlit
- Pandas
- Scikit-learn
- XGBoost
- Joblib

## Use Case
This system can assist insurance providers in identifying potentially fraudulent claims and prioritizing cases for further investigation.
